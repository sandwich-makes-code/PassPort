## What is PassPort?
PassPort is a utility meant to be used to disable Windows requirements either inside the setup environment or your desktop for easy and *reliable* use.

### Setup Guide

> Windows may flag this as a virus due to it interacting with the registry.

1. Download the PassPort.exe file located below.
2. Right-click it and press Run as administrator.

The checkboxes located on the left are the buttons used to disable the Windows requirements, and the **Apply Changes** button below is to apply the settings you set on the checkboxes.
